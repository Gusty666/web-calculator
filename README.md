# 🌟 科学计算器 | Web Calculator

![科学计算器预览](web-calculator.jpg)

一个美观现代的网页科学计算器，支持基础四则运算与高级科学计算功能（平方根、阶乘、幂运算等）。

## ✨ 功能亮点

- 磨砂玻璃风格 UI，视觉舒适
- 支持科学计算：√、x!、x²、x³ 等
- 响应式设计，支持手机和平板
- 操作流畅，即点即算

👉 **[立即体验在线版本](https://gusty666.github.io/web-calculator/)**

## 🛠 技术栈

- **前端**：HTML5 + CSS3 + JavaScript (原生)
- **部署**：GitHub Pages
- **样式**：现代磨砂玻璃效果 + 响应式设计

## 📖 使用方法

1. 打开在线链接即可使用
2. 支持键盘输入（部分功能）
3. 点击 `C` 清空显示屏
4. 点击 `DEL` 删除最后一个字符
5. 支持科学运算（如 `5!`、`√16`、`2^10` 等）
